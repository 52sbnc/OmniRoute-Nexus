# OmniRoute Nexus（寰宇·多级智能导流系统）
由于土耳其客户的需求我开发了这个项目

作者：TG@letoibot

OmniRoute Nexus 是一个面向海外跨境业务场景的多级智能流量调度与高可用跳转系统。项目采用分布式域名调度、主备冗余容灾、随机/加权负载均衡和统一落地配置能力，适用于需要多入口、多中转、多落地域名进行高可用流量分发的合法业务场景。

系统默认针对欧洲德国法兰克福骨干服务器节点部署进行优化，并可针对土耳其区域访问路由进行网络延迟与丢包优化。

> 本项目仅用于合法授权范围内的流量调度、系统容灾与运维管理。使用者应遵守所在国家/地区法律法规、目标平台规则及网络安全要求。不得将本项目用于规避监管、绕过平台风控、封禁拦截、欺诈、侵权、恶意跳转或其他违法违规用途。

## 1. 项目特性

- **多入口域名集群**：支持配置多组独立入口域名，按策略随机或加权分配流量。
- **主备冗余中转**：支持主中转域名常驻、备用中转域名热备，健康检查失败时自动切换。
- **分布式落地分流**：支持多组落地域名集群，对中转流量进行二次分流与负载均衡。
- **统一目标落地配置**：后台统一配置终极落地 URL，全局链路联动更新。
- **健康检查与故障切换**：支持 HTTP/TCP 健康检查、失败重试、自动摘除与恢复。
- **可观测性**：支持访问日志、切换日志、指标监控与告警接入。
- **极简运维**：支持配置文件、环境变量和后台管理方式维护域名池与落地地址。
- **区域网络优化**：支持欧洲法兰克福节点部署，并可针对土耳其区域进行路由与缓存优化。

## 2. 系统架构

OmniRoute Nexus 采用四层流量调度架构：

```text
用户访问
   │
   ▼
┌──────────────────────────────┐
│ 1. 全域入口分发层             │
│    多入口域名集群             │
│    随机/加权分发              │
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 2. 智能中转冗余层             │
│    主中转 + 备用热备          │
│    健康检查与自动切换         │
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 3. 分布式落地分流层           │
│    多落地域名集群             │
│    二次分流与负载均衡         │
└──────────────┬───────────────┘
               ▼
┌──────────────────────────────┐
│ 4. 终极目标落地层             │
│    统一业务落地 URL           │
│    全局联动更新               │
└──────────────────────────────┘
```

## 3. 环境要求

PHP 8.1 以上，MySQL 5.7 或 8.0，Redis。PHP 要装 `pdo_mysql` 和 `redis` 扩展，发通知的话还需要 `curl`。

## 4. 安装

先建库，再导入 `database.sql`：

```bash
mysql -uroot -p -e "CREATE DATABASE \`daoliu\` DEFAULT CHARACTER SET utf8mb4;"
mysql -uroot -p daoliu < database.sql
```

然后改 `config/config.php`，把数据库账号密码填上。`app.key` 和 `app.cron_token` 也换成自己的随机字符串，Redis 有密码的话一起填。

配置好以后访问 `/admin/`，默认账号是 `admin`，密码 `admin888`。进去先改密码，再去「系统设置」把最终落地地址和兜底地址填好，然后在域名池里把各层域名加进去，就能跑起来了。

## 5. 定时任务

域名检测、轮换和日志清理都靠定时任务，建议 5 分钟跑一次。

用命令行：

```bash
*/5 * * * * cd /path/to/project && php task.php >> runtime/logs/cron.log 2>&1
```

或者用宝塔的 URL 计划任务：

```text
http://你的域名/task.php?token=你的cron_token&job=check
```

`token` 要和配置里的 `app.cron_token` 一致。`job` 可以是 `check`、`rotate`、`cleanup`，不填就全部执行。

## 6. 上线前记得

- 改掉默认管理员密码，`app.key` 和 `app.cron_token` 也别忘了换。
- 数据库别用 root，给当前库的最小权限就行。
- 能上 HTTPS 就上，后台也能开强制 HTTPS。
- `runtime/` 里是日志和备份，别让外网直接访问到。
